# Team Working Agreement – TechNinjas

This agreement outlines how our team collaborates to maintain velocity, quality, and respectful communication.

---

## 👥 Roles

- **Maintainer:** Oversees merges, enforces governance, and manages CI health.
- **Reviewer:** Provides timely feedback and approvals based on CODEOWNERS.
- **Contributor:** Opens PRs, follows checklist, and responds to review comments.
- **CI Owner:** Ensures CI pipeline is functional and status checks are enforced.

---

## ⏱️ Review SLA

- First review response within **24 hours**
- Approvals expected within **48 hours**
- Use GitHub comments for feedback and decisions
- Tag teammates respectfully if review is delayed

---

## 📆 Merge Queue Cadence

- Merges are reviewed and processed **daily between 18:00–20:00 EET**
- Squash merges preferred to maintain clean history
- PRs must pass CI and meet checklist before merging

---

## 📣 Communication Channels

- Primary: GitHub comments and PR threads
- Secondary: Microsoft Teams for real-time coordination
- Escalation: Direct message to Maintainer if review is stalled >48h

---

## 🤝 Conflict Resolution

- Discuss conflicting changes in PR comments
- Prefer merge or rebase with manual resolution (no “ours/theirs” blanket)
- Run tests and verify before finalizing resolution

---

This agreement is reviewed periodically and updated based on team feedback.
