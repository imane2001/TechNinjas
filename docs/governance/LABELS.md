# Labels – TechNinjas

This document defines the labels used in this repository to organize issues and pull requests.

---

## 🟢 Status Labels
- **status: in-progress** – Work actively being done
- **status: blocked** – Waiting on dependency or review
- **status: ready-for-review** – PR is complete and awaiting feedback
- **status: needs-info** – More details required before proceeding

---

## 🔧 Type Labels
- **type: feature** – New functionality
- **type: bug** – Defect or error fix
- **type: docs** – Documentation updates
- **type: chore** – Maintenance or non-functional changes
- **type: test** – Adding or updating tests

---

## 🎯 Priority Labels
- **priority: high** – Must be addressed immediately
- **priority: medium** – Important but not urgent
- **priority: low** – Nice-to-have or backlog item

---

## 🤖 Governance Labels
- **governance: ai-assisted** – PRs where AI tools were used
- **governance: conflict-resolution** – Branches or PRs created to resolve merge conflicts
- **governance: audit** – Items flagged for governance evidence or compliance

---

## 📝 Notes
- Labels are applied consistently to issues and PRs.
- Governance labels ensure transparency and audit readiness.
- Reviewers may add or adjust labels during triage.
